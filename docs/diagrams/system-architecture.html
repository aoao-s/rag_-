分层与依赖方向

  • main.py（接入）→ 业务模块 → base/ → 外部服务，方向不可逆，反向 import 一律打回。
  • qa_system 与 rag_system 互不 import，只通过 base/contracts.py 的数据类协作。
  • 只有 base/db.py 与 qa_system/res/qa_cache.py 允许建连接，业务层拿 repository。
  • 新增能力先判断归属：理解 / 检索 / 生成 / 知识 / 基础设施，放错层直接打回。

在线请求链路

  • 鉴权限流 20 ms → 归一化改写 80 ms → L1 精确缓存 10 ms。
  • FAQ ∥ 意图 ∥ 记忆召回并行 120 ms，三路各自独立超时，FAQ 不该被记忆拖慢。
  • 检索 + 重排 350 ms → 证据门 5 ms → 生成吃剩余预算。
  • 总预算 8 s；首 token p95 ≤ 1.2 s，完整答案 p95 ≤ 4 s。

离线摄入链路

  • 12 种后缀：md / txt / srt / docx / pptx / pdf / 图片 OCR，工厂按后缀分派。
  • 父块 1200 / 子块 300，子块继承父块标题树；命中后按 parent_id 回填。
