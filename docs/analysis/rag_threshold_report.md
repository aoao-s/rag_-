# RAG 证据门标定报告

- 样本：763 条（黄金集 `datasets/07_eval` 中带 contexts 的题），其中可答 154 / 不可答 609
- 相关性判据：某条证据对黄金事实的词覆盖 ≥ **0.5**（`contexts` 是事实依据，不是原文）
- 检索：融合分（无重排），top_k=40 / final_n=10，CPU 上 p50 632 ms / p95 822 ms
- Recall@1 / @3 / @6 / @10（全样本）：**0.0826 / 0.1455 / 0.1769 / 0.2018**
- top1 证据对黄金事实的平均覆盖：0.129

> 召回率低主要是**语料不齐**：当前语料只有 6 份短教材 + 6 份教案 + 1 本九年级数学 PDF，
> 黄金集却覆盖 7–9 年级全部知识点（有理数、数轴这些七年级内容语料里没有）。
> 所以门槛只在「可答 / 不可答」两个子集上评，不能拿全体召回率评价门槛。

## 结论

建议 **RAG_EVIDENCE_THRESHOLD=0.74**、**RAG_EVIDENCE_MARGIN=0.0**、**RAG_EVIDENCE_QCOV=0.2**：不可答题的误放行率 **3.6%**（≤5%），同时可答题放行 **38.3%**；被放行的答案里 top1 相关率 35.8%。
