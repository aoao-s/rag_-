## 建议

- 只看绝对分：**0.60**（召回 0.069、精度 0.971、误命中 1 条）。
- 加 margin 约束：**threshold=0.25 + margin=0.10** → 召回 0.637、精度 0.950、误命中 16 条。

选点原则：FAQ 答错（把 A 问题的答案给 B）比不答更伤信任，不答还能交棒 RAG。因此先卡精度 ≥0.95，再最大化召回；margin 是在同题族（内容 / 证明 / 应用）之间保命的那个旋钮。
