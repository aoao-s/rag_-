## 判据可达性

- 全网格（三套 margin 空间 × 81 个阈值）在 test 上的最好精度：**1.000**（召回 0.180，`relative` / 0.10 / 0.65）
- 精度 0.95 可达，但代价是召回只剩 0.180——特征能分开的只有最干净的那一小撮；召回要到 0.637 时精度上界见「反向选点」。两根旋钮（threshold + margin）到此为止，把剩下的区间交给下一阶段的机制（三档路由）。

## 结论

**样本来源为 `source=rule`（规则改写），结论只能算临时值。**
规则变体的词面偏离比真实口语小，分数分布偏高，标出来的阈值会偏保守（宁可漏答）；
拿到生成模型密钥后必须重跑 `gen --source llm` + `calibrate`，才可作为改写线上默认参数的依据。

- 本次 dev 选点（`relative` / 0.56 / 0.15）在独立 test 上的精度：0.935、召回 0.376 → **未通过** §7.1.7 第三步验收（precision ≥0.95 且 recall ≥0.637）。
- **不建议据此改动线上参数**：dev 上过闸、test 上不过。dev 只有 581 条负样本，一条就是 0.17 个百分点精度；test 只有 259 条，一条是 0.39 个百分点——精度 0.95 这道闸门在两个集合上都贴着噪声，选点落在边界上就会翻。
- 反向问法给出的上界：把召回守在现基线 0.637，dev 上能选到的最好精度是 0.911（test 0.870）。两根旋钮（threshold + margin）到此为止——要精度只能把召回砍到 0.1 量级。
- 现行默认（`normalized` / 0.25 / 0.10）在 test 上是召回 0.735、精度 0.859，本身已落在前沿上，继续调参没有真实的收益空间。
- 分数分辨力不足：正样本 p90 0.631 / max 0.727，负样本 p90 0.507 / max 0.742——负样本的高分尾部伸进正样本主体里，单一阈值只能二选一。
- 长查询靠词数堆分：`21–40` 字区间负样本误命中率 0.273、正样本召回却只有 0.800（见长度切片）——同一区间两头都变差：BM25 原始分随命中词数增长，`score_norm` 只是单调压缩，分不清"题干里出现这些词"与"问的就是这件事"。
- 判定里没有任何"查询形态"信号（概念题 / 选择题 / 计算题），也拿不到同题族结构；只用（分数 + margin + 候选数）这些特征时，上面就是精度上界。
- 第四步（三档路由 §7.1.9）已落地：见「三档路由」一节的 `high` / `mid` / `low` 分档，中置信命中不再直接作答，而是交 RAG + top1 追问——这段"答不准"的区间交由机制消化，不再指望把 threshold / margin 调到两者同时达标。
- 仍待做（§7.1.7 第五、六步）：线上反馈闭环（追问采纳率、high vs mid 点踩率）与查询形态 / 同题族二次判别——若要让 FAQ 自己扛住精度，后者才是有希望的路。

选点原则：FAQ 答错（把 A 的答案给 B）比不答更伤信任，不答还能交棒 RAG。
因此先卡精度 ≥0.95，再最大化召回；margin 是在同题族（内容 / 证明 / 应用）之间保命的旋钮。

## 三档路由（§7.1.9；现行 `normalized` / threshold=0.25 / margin=0.10 / high_margin=0.22）

「若直接答的精度」= 该档内 `答对 / (答对 + 答错 + 负样本)`；线上只有 `high` 档会直接返回答案，`mid` 只给候选与追问，`low` 交棒 RAG。「占召回」= 该档答对数 ÷ 该集合正样本总数。

| 档 | 集合 | 正样本 | 答对 | 答错 | 负样本 | 若直接答的精度 | 占召回 |
|---|---|---|---|---|---|---|---|
| `high` | dev | 141 | 141 | 0 | 8 | 0.946 | 0.227 |
| `mid` | dev | 298 | 298 | 0 | 81 | 0.786 | 0.479 |
| `low` | dev | 183 | 169 | 14 | 492 | — | 0.272 |
| `high` | test | 89 | 89 | 0 | 4 | 0.957 | 0.291 |
| `mid` | test | 136 | 136 | 0 | 33 | 0.805 | 0.444 |
| `low` | test | 81 | 71 | 10 | 222 | — | 0.232 |

- high 档 test：精度 **0.957**、召回 **0.291** → **通过** §7.1.9 验收（高置信精度 ≥0.95 且召回 ≥0.25）。
- mid 档「若直接答」的精度：**0.805**（答对 136 / 若作答 169）——这就是「中置信不许直答」的量化依据；它的去处是 RAG 答案 + top1 追问，不是 FAQ 原文。
- low 档（含 `reject_*` 与单候选）承载剩余 81 条正样本，全部交棒 RAG；候选照旧带进 query 扩展，不浪费这段被拒的信号。
