## 3. 开训前要处理的四件事

### 3.1 切 dev 集（必做，5 分钟）

仍只有 train/test。从 4 080 条里分层抽 10%（408 条）作 dev，剩 3 672 训练；test 1 020 条只在最终验收用。

### 3.2 近重复 4.4%：报告两个数即可，不必重切

45 条近似（如"验算一下配平…" vs "讲一下配平…"）会让测试指标略微虚高。1 020 条里 45 条，影响约 1–2 个点——可以接受，但验收报告要同时给：

- **主指标**：去掉 45 条后的 975 条 macro-F1（对外口径）；
- **上限值**：全 1 020 条（内部参考）。

两者差距 >5pp 才说明模型在背句式，届时要按模板前缀分组重切。

### 3.3 长度捷径仍在（20.1 字 vs 5.3 字）

题目讲解平均 20.1 字，闲聊 5.3 字，差近 4 倍。模型可以靠长度蒙对。**补 100 条 ≤10 字的题目讲解**（"这道题怎么做""浮力这题怎么入手"）即可拉开混淆，不必大改数据集。

### 3.4 新增发现：`备课辅助` 与 `教案素材` 的边界是句式，不是语义

| 说法 | 当前标签 | 语义 |
|---|---|---|
| "帮我设计电功率的课堂活动" | 备课辅助 | 要"怎么教" |
| "能给我电功率的课堂活动方案吗" | 教案素材 | 要"现成的方案" |

两条语义几乎相同，标签却不同，区分点落在"设计/怎么" vs "有没有/给我"。这是**可辩护的**——因为下游动作不同（备课辅助 → 生成教学设计；教案素材 → 检索教案库），但必须写进标注规范，否则模型学到的是句式。

建议把判定规则固化成三句话，后续增量标注直接照抄：

1. 要**成品文件/材料**（课件、试卷、学案、视频、板书）→ `教案素材`；
2. 要**教学思路**（怎么组织、怎么设计、几个课时、什么方法）→ `备课辅助`；
3. 两者都像时，看向下要什么：能给链接/文件 → 素材；要一段方案文字 → 辅助。

### 3.5 少量模板痕迹（可选清洗）

抽查见到 "…的用法是什么"（"法国大革命的用法是什么"）、"…适合做几个课时" 这类明显套模板生成的表达。不影响训练，但如果要对外展示数据质量，建议对 30–50 条做一次人工润色，改成教师真实说法。

## 4. 训练配置（按下表跑即可）

| 项 | 值 |
|---|---|
| 基座 | `bert-base-chinese`（备选 `hfl/chinese-roberta-wwm-ext`） |
| 输入 | query，`max_length=64`，`padding=max_length` |
| 优化 | AdamW，lr 2e-5，weight_decay 0.01，warmup 10% |
| 批次 | 32（显存够用 64） |
| epoch | 3–5，按 dev macro-F1 early stop（patience=1） |
| 损失 | CrossEntropy + label_smoothing=0.1（不再需要 class weight，已均衡） |
| 评估 | macro-F1 + 每类 P/R + 混淆矩阵 + 长度分桶准确率 + ECE |
| 校准 | temperature scaling，低置信拒识 |
| 导出 | ONNX 动态 batch，CPU 单条 <5 ms |

验收线：去重测试集 macro-F1 ≥0.90、闲聊召回 ≥0.90、ECE ≤0.05、单条 P95 ≤5 ms。

**推理侧注意**：训练集均衡（16.7%），但线上闲聊占比更高。上线时按真实先验做一次 prior correction（或直接调低闲聊阈值），否则闲聊会被系统性低估。

## 6. 产品边界（仍然需要拍板，但不阻塞训练）

数据集口径是 **K12 教学 6 类**（知识点查询 / 题目讲解 / 教案素材 / 学习方法 / 备课辅助 / 闲聊），而 `CLAUDE.md` 与架构书里写的是招生咨询 5 类。

`datasets/README.md`、`04_faq`（学科名称/问题/答案）、`03_question_bank`（15 865 道）、`07_eval`（带 intent 字段）、`01_textbook`、`02_lesson_plans` 全套都按 K12 教学组织——**以数据集为准是自洽的选择**。训练可以先按 6 类跑，文档改口径等你一句话。
